# Sprint 7 — Machine Learning Fundamentals for AI/ML Engineers

Notebook-based learning and assessment for Sprint 7, following the same methodology as prior sprints:
**Concept → Demonstrate → Implement → Interpret** for every topic.

Continues on from Sprint 6 (Feature Engineering & Feature Selection). Objective for this sprint:
understand how Machine Learning actually works — not just how to call `fit()` / `predict()` — covering
the core theory behind supervised and unsupervised learning, the major classical algorithms, and how to
properly evaluate whether a model is performing well.
